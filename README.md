# Folder Image Viewer

A small desktop app for browsing images in a folder. It supports BMP, GIF, JPEG, PNG, TIFF, and WebP files.

## Run

From this folder, install the dependency and start the app:

```powershell
python -m pip install -r requirements.txt
python main.py
```

Choose **Open folder...** to load a folder. Use the Previous and Next buttons or the left and right arrow keys to browse.
